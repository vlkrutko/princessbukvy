# Принцессобуквы

Веб-приложение (PWA) для обучения чтению на русском с тематикой диснеевских принцесс:
звуки → слоги → слова → фразы → истории.
Рассчитано на iPad, открывается в Safari и ставится через «Поделиться → На экран Домой».

## Содержание

- **Звуки** — 3 уровня: слово на слух → выбрать первую букву.
- **Слоги** — 5 уровней: складывание слога из двух букв + выбор по звучанию.
- **Слова** — 4 уровня: два открытых слога → три открытых → закрытые слоги и кластеры → имена принцесс.
- **Фразы** — 5 уровней: от 2-словных до развёрнутых предложений.
- **Истории** — 5 историй: Ариэль, Золушка, Белль, Рапунцель, Аврора.

## Запуск

```powershell
npm install      # один раз
npm run dev      # http://localhost:5174, с iPad — http://<адрес-компьютера>:5174
npm run build    # сборка в dist/ для выкладки
```

iPad и компьютер должны быть в одной сети Wi-Fi. Офлайн-режим и запись голоса
работают только по HTTPS, то есть после выкладки `dist/` на хостинг.

## Выкладка

Сайт: https://vlkrutko.github.io/princessbukvy/ — собирается и публикуется сам
(GitHub Actions, `.github/workflows/deploy.yml`) после `git push origin main`.
Из-за офлайн-кэша новая версия на устройстве видна со второго запуска.

## Озвучка

Реплики записаны заранее нейросетевым женским голосом (Microsoft Edge TTS,
`ru-RU-SvetlanaNeural`) в `public/audio/`. После правки слов, фраз или историй
в `src/content.ts` дозаписать новое (нужен интернет):

```powershell
.venv\Scripts\python.exe tools\make_audio.py           # только недостающее
.venv\Scripts\python.exe tools\make_audio.py --force   # всё заново (сменили голос, темп, высоту)
```

Голос, темп и высота — константы в начале `tools/make_audio.py`; там же словарь
`STRESS` для слов с неверным ударением. Окружение `.venv` создаётся так:
`python -m venv .venv; .venv\Scripts\pip install edge-tts`.
Текст без записи приложение читает синтезатором устройства.

## Где что

- `src/content.ts` — весь учебный материал (слова, слоги, уровни) и сборка заданий;
- `src/Play.tsx` — занятие и виды заданий;
- `src/App.tsx` — карта этапов и выбор уровня;
- `src/speech.ts` — озвучка (записанные файлы, запасной путь — синтезатор), `src/sfx.ts` — звуки-отклики;
- `tools/make_audio.py` — запись озвучки, `src/audio.json` — её список (создаётся скриптом);
- `src/progress.ts` — звёзды по уровням (localStorage устройства);
- `public/sw.js` — офлайн-кэш.
